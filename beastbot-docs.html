// NACHRICHTEN-FLOW
message processing pipeline
1. messages.upsert → Nachricht empfangen
2. AutoSticker Check → Sticker löschen wenn aktiviert
3. body = null? → return (kein Text)
4. Timeout Check → User im Timeout → Nachricht löschen
5. readMessages → Als gelesen markieren
6. AFK Mention Check → Erwähnte AFK-User benachrichtigen
7. Group Features → AntiNSFW/AntiSpam/Leveling/AntiLink/Badwords
8. AFK Return Check → War User AFK? → zurück online
9. Prefix Check → Kein Prefix → return
10. IP-Ban Check → Gesperrte LID/IP → abbrechen
11. User-Ban Check → Gebannter User → nur /unbanrequest erlaubt
12. Register Check → Nicht registriert → nur /register erlaubt
13. LockGroup Check → Gruppe gesperrt → nur Team darf
14. XP vergeben → +6 XP pro Command
15. DisabledCommands → Command global deaktiviert?
16. switch(command) → 180+ Cases verarbeiten
17. default: → Levenshtein-Suggestion ("Meintest du...?")
